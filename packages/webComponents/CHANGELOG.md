# 变更记录

## 未发布

- Tooltip 增加 Escape 关闭、同树描述关联、边缘翻转与定位更新、主题变量，以及卸载时资源清理。

- 修复数字输入小数步进尾数与动态边界校正；分页归一化非法参数、整数页码和数据缩减后的当前页。
- 折叠菜单保留可访问名称并统一默认选中高亮；进度条忽略非有限数值，头像占位保留完整字素。

- 新增 `su-typewriter`：五种文字效果、四种光标、删除轮播、暂停/继续/重播、字素分割与减少动态效果适配。
- 打字机文档提供交互演示、按需/Vue 接入、完整 API 与主题定制；文档首页复用组件并清理动画资源，修复子路径部署导航。

- 主题恢复忽略损坏或结构异常的本地存储，仅恢复已知颜色字段，避免阻断应用启动。
- 修复消息和通知的卸载、重挂载及持续时间更新行为，避免遗留计时器和重复关闭事件。
- 表格排序提供键盘可达的原生按钮与 `aria-sort`；修复分页事件重复转发和远程模式初始页码重置。
- 补齐表格 API、服务端请求与错误处理、按需主题接入文档，并明确体积阈值统计范围。
- 提供 44 个独立组件入口，覆盖 45 个自定义元素，并提供独立主题 API 入口。
- 支持品牌色切换、明暗主题和持久化恢复；换主色时重新派生 hover 色。
- 表格支持固定列、鼠标与键盘调宽、可展开行、服务端分页排序。
- 增加 Vue 按需接入示例、公开入口类型验证和交互卸载回归测试。

### 使用与兼容说明

- 全量入口、CommonJS 和 UMD 保持兼容；按需入口使用 ESM。
- 按需引入需要加载 `webcomponents/style.css`，持久化主题通过 `initTheme()` 恢复。
- 服务端表格设置 `remote`、`total`、`currentPage`，由业务层监听分页与排序事件请求数据。
- 可展开行关闭虚拟渲染；合并单元格不应跨越详情行。
- 当前版本仍为 `0.0.0`；本次工作不发布 npm 包或创建版本标签。

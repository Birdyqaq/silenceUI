2026-10-31 新增 `pnpm typecheck:browser` 与 `pnpm test:browser`。首次运行先执行 `pnpm exec playwright install chromium`。18 项真实 Chromium 测试覆盖原生表单、键盘焦点、异步规则与卸载、明暗/品牌色及宽窄屏；报告和失败诊断文件不提交。GitHub Actions 远端结果需另行确认，不等于本地通过。

```bash
pnpm docs:verify
pnpm docs:inventory:check
pnpm docs:build
pnpm check
```

`docs:verify` 根据 `docs/components` 自动枚举组件使用页面（2026-10-28 为 17 页），检查它们均有客户端演示入口、公开组件均出现在 README 与可达演示源文件中、Button 属性名和 React 布尔传值约定正确，以及在线媒体不依赖远程地址。实际数量以命令输出为准。`se-image-preview` 通过图片点击打开，不独立常驻展示。Table 设计说明和组件总览是说明/索引页面，不计入交互页面。

这项检查是静态约定验证；它不替代示例运行、React 宿主类型检查或浏览器兼容性测试。VitePress 构建负责页面与站内链接，组件 API 清单来自源码。

## 实测范围与发布前检查

本轮在 Codex 内置浏览器中验证在线组件页面加载，以及表格排序/分页、导航切换、反馈弹层、表单重置与主题操作。验收结果不代表所有参数组合均已覆盖。

2026-10-19 增补验证：表单 name property 反射后可提交；fieldset 禁用时原生输入不可操作且提交为空，重新启用后字段值恢复。新增回归覆盖 10 类控件的改名/移除与继承禁用、无主键跨页选择、虚拟窗口缩减，以及 Tooltip 动态触发器清理。

发布前仍需要在目标 Chrome、Firefox、Safari 和移动真机上检查键盘/读屏、原生表单、日期和文件输入、视频音频编码、PDF 预览与动态布局。媒体源示例、npm 发布状态与公网 CDN 连通性不由本地构建保证；安装指南将 CDN 地址标记为发布后的格式示例。

## 2026-11-04 本地发布演练

`pnpm check` 通过 TypeScript、ESLint、335 项单元测试、公开类型、文档构建与发布包检查。归档包含 57 个按需组件入口，单入口上限为 80 KiB，gzip 上限为 20 KiB。检查归档 source map 中是否包含整套 Lucide 数据。大型交互采用固定的 1,000 项角色全选与部门搜索、2,000 行表格虚拟窗口场景，断言结果和渲染窗口大小。

`bash scripts/verify-consumers.sh --browser` 从同一个本地 tarball 独立安装并构建 Vue 与 React，验证根入口注册、按需接入、表单、主题和事件清理。后台演示覆盖表格、角色、部门与排班的本地状态联动。API 以公开声明和[生成清单](./component-inventory)为准，安装步骤见[安装指南](./installation)，发布内容见包内 CHANGELOG。

### AutoComplete 浮层扩展验收

首轮路线图完成后，候选面板接入共享顶层定位，新增抽屉内键盘定位、滚动到最后一项、点击选中及 Escape 分层关闭的回归。组件清单补齐 query/change 事件和 CSS Parts。后续全量验收通过 335 项单元测试和四个桌面项目各 48 项浏览器测试，共 192 项。浏览器矩阵在构建结束后独立运行，避免开发服务热重载干扰页面。

### DateTimeRange 扩展验收

新增本地日期时间范围组件后，单元测试合计 348 项通过，桌面四项目矩阵合计 200 项通过。新增场景覆盖跨日、跨年、日期边界和格式、错误焦点、原生 FormData 同名字段、状态恢复、重置、fieldset 禁用、只读与窄屏暗色布局。发布归档包含 58 个按需组件入口。日历时间不携带时区，服务端转换与夏令时歧义由应用定义。

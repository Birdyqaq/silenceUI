# 文档验收

## 自动检查

```bash
pnpm docs:verify
pnpm docs:inventory:check
pnpm docs:build
pnpm check
```

`docs:verify` 检查 12 个组件使用页面均有客户端演示入口、公开组件均出现在 README 与演示源文件中、Button 属性名和 React 布尔传值约定正确，以及在线媒体不依赖远程地址。`se-image-preview` 通过图片点击打开，不独立常驻展示。Table 设计说明和组件总览是说明/索引页面，不计入交互页面。

这项检查是静态约定验证；它不替代示例运行、React 宿主类型检查或浏览器兼容性测试。VitePress 构建负责页面与站内链接，组件 API 清单来自源码。

## 在线演示

| 页面                       | 可操作示例                                                         |
| -------------------------- | ------------------------------------------------------------------ |
| Button / Input             | 按钮状态、波纹、表单提交/重置及文本输入                            |
| Form                       | 原生表单示例与日期、级联、文件选择、数字步进、单选、开关、多行输入 |
| Data                       | 卡片/指标、标签/徽标、头像、详情、树、空态、骨架屏                 |
| Table                      | 本地排序、行选择、分页以及独立分页器                               |
| Navigation                 | 菜单、面包屑、Tabs、下拉操作、步骤条                               |
| Feedback                   | Modal、Drawer、消息、通知、警告、确认气泡、Tooltip、加载与进度     |
| Layout                     | 页面骨架、分割线及主题切换                                         |
| Typewriter                 | 五种效果、光标、速度和播放控制                                     |
| Image / AssetViewer / Line | 本地图片、预览与缩略图、历史分割线                                 |

交互演示等待组件注册后再传 property，事件结果直接显示在页面上。消息和通知在离开示例页面时清理；表单按钮通过原生 submit/reset 触发，避免点击与表单事件重复调用。

文档站的明暗切换与组件主题双向同步，避免站点背景变暗后示例仍使用浅色文字/背景配置。此同步层仅属于文档站，业务应用仍按主题指南接入。

## 实测范围与发布前检查

本轮在 Codex 内置浏览器中验证在线组件页面加载，以及表格排序/分页、导航切换、反馈弹层、表单重置与主题操作。验收结果不代表所有参数组合均已覆盖。

2026-10-19 增补验证：表单 name property 反射后可提交；fieldset 禁用时原生输入不可操作且提交为空，重新启用后字段值恢复。新增回归覆盖 10 类控件的改名/移除与继承禁用、无主键跨页选择、虚拟窗口缩减，以及 Tooltip 动态触发器清理。

发布前仍需要在目标 Chrome、Firefox、Safari 和移动真机上检查键盘/读屏、原生表单、日期和文件输入、视频音频编码、PDF 预览与动态布局。媒体源示例、npm 发布状态与公网 CDN 连通性不由本地构建保证；安装指南将 CDN 地址标记为发布后的格式示例。

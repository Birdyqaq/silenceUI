# 常规后台组件缺口与扩展顺序

本清单依据 2026-10-27 本仓库源码盘点，不代表已有组件已达到复杂业务所需的全部能力。

2026-10-28 已补充[整体盘点与 30 天执行计划](./30-day-plan)，包含质量门禁、时间选择、Table 深化、后台页面组件及联动验收；具体实施状态以该计划为准。

## 本批完成

- Transfer：双侧搜索、当前结果全选、双向批量移动及原生表单校验；不包含权限保存和远程分页。

- TreeSelect：部门树单多选、搜索、清空、原生表单和错误关联；禁用子树不可操作，独立多选不级联。

- Collapse 折叠面板：配置分组、多开/手风琴、禁用、富内容插槽与键盘导航。
- Timeline 时间线：审批/审计日志、状态色、时间说明与反序展示。
- Tabs：可关闭页签、固定首页、取消关闭与相邻回退；路由和页面缓存仍由宿主负责。
- 已有基础：Form/DateRange、Select 搜索多选、Menu 多级导航、Table 文本筛选与 Tree 权限勾选。详细边界见[后台管理增强](/components/admin)。

## 后续优先级

| 优先级 | 待补能力                           | 常见场景               | 需要同时解决的边界                                |
| ------ | ---------------------------------- | ---------------------- | ------------------------------------------------- |
| P1     | TimePicker / 日期时间范围          | 排班、有效期、定时任务 | 时区约定、跨日、最小最大值、原生表单桥接          |
| P1     | Table 编辑与列设置                 | 数据维护与大型列表     | 行/单元格校验、保存失败恢复、显隐持久化、筛选组合 |
| P1     | PageHeader / 页签路由适配          | 多页工作台             | 页签关闭已支持；路由与缓存仍由宿主负责            |
| P2     | AutoComplete                       | 用户/地址检索          | 输入值与选择值区分、异步竞态、键盘列表导航        |
| P2     | Result 结果页 / Segmented 分段控制 | 提交结果、视图切换     | 命名动作插槽、选中与禁用状态、键盘语义            |
| P2     | Calendar / 通知中心                | 日程和站内消息         | 月边界、本地化、未读状态与分页接口                |
| P3     | 图表适配、富文本、拖拽排序         | 经营大屏、内容运营     | 优先独立适配层，不把大型依赖强加给基础包          |

## 已有组件仍需增强

Table 当前筛选为原字段文本匹配，不等同于枚举/区间筛选；Menu 尚无收起后的浮层子菜单。Upload 负责选文件和校验，不负责断点续传。DatePicker/DateRange 仍采用浏览器日期输入，不等同于自研日历面板。权限树仅提供前端交互，不能替代服务端鉴权。

推进每批组件时同步根/按需入口、类型声明、主题、文档活例、键盘及非法数据测试，再通过完整检查；不以组件数量代替业务完成度。

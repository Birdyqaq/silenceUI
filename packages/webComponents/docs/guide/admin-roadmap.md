# 常规后台组件缺口与扩展顺序

本清单在 2026-11-04 完成首轮验收后更新，记录后台组件已交付的能力与下一轮扩展边界。

2026-10-28 已补充[整体盘点与 30 天执行计划](./30-day-plan)，包含质量门禁、时间选择、Table 深化、后台页面组件及联动验收；具体实施状态以该计划为准。

## 本批完成

- [WeekSchedule](../components/week-schedule) 提供周排班浏览与选择，[SortableList](../components/sortable-list) 提供桌面拖动和键盘、触屏排序。

- 2026-11-04 Table：文本/数字编辑、异步校验与宿主保存回调，验证固定列、分页、筛选及虚拟窗口的基础联动；本地分页可启用跨页草稿恢复。

- 2026-11-03 Table：列显隐/组内顺序、状态导入导出和宽度恢复、枚举与数值区间筛选已实现，见[Table](../components/table)。编辑与异步保存已在第 14—16 天交付。

- DateTimeRange：本地日期时间范围、跨日排班、有效期边界与原生表单已补充，见[日期时间范围](../components/time#日期时间范围与跨日排班)。时区及夏令时解释由宿主负责。

- TimePicker / TimeRange：本地 HH:mm、原生表单与排班活例，见[时间选择](../components/time)。秒、跨日、时区与日期时间范围仍不支持。Table 接口与边界见[约定](./table-contract)。

- Transfer：双侧搜索、当前结果全选、双向批量移动及原生表单校验；不包含权限保存和远程分页。

- TreeSelect：部门树单多选、搜索、清空、原生表单和错误关联；禁用子树不可操作，独立多选不级联。

- Collapse 折叠面板：配置分组、多开/手风琴、禁用、富内容插槽与键盘导航。
- Timeline 时间线：审批/审计日志、状态色、时间说明与反序展示。
- Tabs：可关闭页签、固定首页、取消关闭与相邻回退；路由和页面缓存仍由宿主负责。
- PageHeader、Result、Segmented 与 AutoComplete 已交付。AutoComplete 候选面板已接入共享浮层定位，并覆盖抽屉中键盘选中和分层关闭。
- 已有基础：Form/DateRange、Select 搜索多选、Menu 多级导航、Table 文本筛选与 Tree 权限勾选。详细边界见[后台管理增强](/components/admin)。

## 后续优先级

| 优先级 | 待补能力                      | 常见场景           | 需要同时解决的边界                                       |
| ------ | ----------------------------- | ------------------ | -------------------------------------------------------- |
| P1     | 高级时间策略与时区适配        | 有效期、跨日排班   | DateTimeRange 已支持跨日；时区、夏令时歧义和秒精度待定义 |
| P1     | Table 远程草稿版本与冲突处理      | 多页批量维护       | 草稿身份、原始版本与并发冲突，先约定分页与重试规则       |
| P3     | 图表适配、富文本编辑器示例    | 经营大屏、内容运营 | 优先独立适配层，不把大型依赖强加给基础包                 |

## 已有组件仍需增强

Table 支持文本、枚举和数值区间筛选；Menu 已支持可选的收起浮层。Upload 负责选文件和校验，不负责断点续传。DatePicker/DateRange 仍采用浏览器日期输入，不等同于自研日历面板。权限树仅提供前端交互，不能替代服务端鉴权。

推进每批组件时同步根/按需入口、类型声明、主题、文档活例、键盘及非法数据测试，再通过完整检查；不以组件数量代替业务完成度。
